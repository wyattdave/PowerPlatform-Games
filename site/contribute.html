🕹️ WANT TO ADD YOUR GAME?

Power Platform Games is an open-source collection of games built with Microsoft Power Platform technologies. We welcome contributions from the community! Follow the steps below to add your own game.

STEP 1: FORK & BRANCH

  1. Go to the repository: github.com/wyattdave/PowerPlatform-Games
  2. Click the Fork button in the top-right corner to create your own copy.
  3. Clone your fork to your local machine:
git clone https://github.com/YOUR-USERNAME/PowerPlatform-Games.git
cd PowerPlatform-Games
  1. Create a new branch for your game:
git checkout -b add-my-game-name

STEP 2: ADD YOUR GAME FILES

Create a folder for your game under the correct platform directory:

Power Apps/Your Game Name/
Power Automate/Your Game Name/
Power BI/Your Game Name/
Power Pages/Your Game Name/
Copilot Studio/Your Game Name/

REQUIRED FILES

Your game folder must contain:

  • README.md — Game description and metadata (see template below)
  • Screenshot image — A PNG/JPG screenshot of your game
  • Solution .zip file — The importable solution package
  • Any additional files your game needs (text files, data files, etc.)

STEP 3: CREATE YOUR README.MD

Use this exact template format so the site can parse your game automatically:

# Your Game Name

## Description
A short description of your game

## Author
YourGitHubUsername
https://github.com/yourusername
https://www.linkedin.com/in/yourprofile/

## Related Links
https://link-to-blog-or-video.com

## Category
Arcade | Puzzle | Simulation | Platform |
Shooter | Sports | Strategy | Unclassified

## Premium
Yes | No

## Depenedencies
None
(or list each dependency)

## Install Guide
Import solution
(or describe the install steps)

## Solution Name
yourgame_1_0_0_1.zip

## Screenshot
your-screenshot.png

## User Guide
Describe how to play the game

STEP 4: UPDATE GAMELIST.MD

Add a new row to the GAMELIST.md file in the repository root. Place your entry at the top of the table (newest first):

| Your Game  | Power Apps | Arcade | No | Easy | YourName | Power Apps/Your Game |

COLUMN REFERENCE

Column Description
NameDisplay name of your game
TypePower Apps, Power Automate, Power BI, Power Pages, or Copilot Studio
CategoryOne of the categories from the Categories page
PremiumYes or No — does it need premium licenses?
GradingEasy, Easyish, Medium, or Effort
AuthorYour GitHub username
FolderRelative path to your game folder

STEP 5: COMMIT & OPEN A PULL REQUEST

  1. Stage and commit your changes:
git add .
git commit -m "Add [Your Game Name] to Power Apps"
git push origin add-my-game-name
  1. Go to your fork on GitHub.
  2. Click "Compare & pull request".
  3. Add a title and description explaining your game.
  4. Submit the pull request to the main branch of wyattdave/PowerPlatform-Games.
  5. A maintainer will review and merge your contribution!

📋 CONTRIBUTION GUIDELINES

  • Make sure your game works in the latest version of Power Platform.
  • Include a clear, concise description and user guide.
  • Add a screenshot so people know what your game looks like.
  • Test your solution import on a clean environment before submitting.
  • Follow the README.md template exactly — the site parses it automatically.
  • Use only the predefined categories from the Categories page.
  • Place your game in the most recent position (top) of GAMELIST.md.
  • Be respectful and constructive in all interactions.

❓ FAQ

DO I NEED TO KNOW GIT?

Basic Git knowledge is helpful, but you can also upload files directly through the GitHub web interface using the "Add file" button on your fork.

WHAT IF MY GAME USES PREMIUM CONNECTORS?

That is perfectly fine! Just set Premium to Yes in both your README.md and GAMELIST.md, and list all dependencies.

CAN I UPDATE MY GAME LATER?

Yes! Just open a new pull request with the updated files. Update the solution zip version and any changed documentation.

HOW DOES THE SITE DETECT NEW GAMES?

The site reads GAMELIST.md for game metadata and each game's README.md for details. When your PR is merged and deployed, your game automatically appears on the site.
